# Compare the Triplets

- **Problem Link:** [HackerRank - Compare the Triplets](https://www.hackerrank.com/challenges/compare-the-triplets/problem)
- **Language:** C++

## Approach
Compare ratings of Alice ($a$) and Bob ($b$) across 3 categories. Increment Alice's score if $a[i] > b[i]$ and Bob's score if $a[i] < b[i]$. Return vector containing $\{ \text{alice\_score}, \text{bob\_score} \}$.

## Complexity Analysis
- **Time Complexity:** $\mathcal{O}(1)$ constant time (3 comparisons).
- **Space Complexity:** $\mathcal{O}(1)$ constant auxiliary space.
